#[Movies_app]

A modern, responsive cross-platform mobile application built using **Flutter** and **Dart**. The app leverages **Bloc/Cubit** for robust state management and applies **Clean Architecture** to maintain high code quality and scalability.

---

## ✨ Features & Functional Highlights
* **Authentication:** User sign-up and login integrated with Firebase.
* **State Management:** Predictable state flow using Bloc/Cubit.
* **Backend Services:** Real-time data sync and database storage via Firebase.
* **Modern UI:** Clean Material Design user interface with responsive layouts.

---

## 🛠️ Tech Stack & Architecture
* **Framework:** Flutter (Dart)
* **Architecture:** Clean Architecture (Presentation, Domain, Data Layers)
* **State Management:** Bloc / Cubit
* **Backend & Storage:** Firebase (Auth, Firestore)
* **Version Control:** Git & GitHub
